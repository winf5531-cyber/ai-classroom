AI 학습실 사용 설명서

한국어 문장 분류하기

  1. 첫 화면에서 텍스트 분류를 선택하세요. 비슷한 뜻의 문장을 모아 둘 긍정 그룹과 부정 그룹을 만드세요.
  2. 각 그룹에서 예시를 추가하세요. 한 줄에 한 문장씩, 그룹마다 서로 다른 문장을 세 개 이상 입력하세요. ‘긍정’에는 ‘친구와 함께 놀아서 즐거웠다.’처럼 자신의 경험을 적어 보세요.
  3. AI 모델 학습하기를 누르고 학습이 끝날 때까지 기다리세요. 이 탭에서 직접 모델을 학습합니다.
  4. 테스트 칸에 학습할 때 쓰지 않은 문장을 입력하고 분류하기를 누르세요. 점수가 높은 그룹부터 살펴보고, 예상과 다른 결과가 나왔다면 예시를 추가해 다시 학습하세요.

먼저 완성된 자료로 연습하려면 파일 메뉴에서 예제 데이터 → 한국어 감정을 여세요. 기존 작업이 있다면 먼저 파일로 저장하세요.

점수 읽기

점수는 모델이 어느 그룹과 더 가깝다고 판단했는지 100점 기준으로 보여 줍니다. 90점이라는 결과만으로 열 번 중 아홉 번 정답이라고 해석할 수는 없습니다. 학습에 쓰지 않은 문장과 사람이 붙인 정답을 따로 모아 실제 성능을 확인하세요.

‘환경을 보호한다.’와 ‘환경을 보호하지 않는다.’처럼 겹치는 표현이 많으면 뜻이 달라도 같은 결과가 나올 수 있습니다. 띄어쓰기와 어미, 부정 표현을 바꿔 결과를 비교해 보세요.

사진 분류하기

첫 화면에서 이미지 분류를 선택하고, 그룹별로 서로 다른 사진을 세 장 이상 올리세요. 카메라를 선택하면 브라우저가 촬영 권한을 요청합니다. 카메라가 없거나 권한을 차단했을 때는 이미지 파일을 사용하세요. 학습이 끝나면 새 사진 한 장으로 테스트하세요.

사진 없이 시작하려면 파일 → 예제 데이터 → 색과 도형을 선택하세요. 빨간 원, 파란 네모, 초록 세모를 학습시킨 뒤 직접 그린 도형을 이미지 파일로 올려 결과를 비교해 보세요.

저장하고 다음 시간에 이어 하기

파일 메뉴에서 학습 데이터 저장을 선택하세요. 다운로드한 JSON 파일에 그룹 이름과 입력한 예시가 들어 있습니다. 다음 시간에 같은 메뉴에서 학습 데이터 불러오기를 선택하고 모델을 다시 학습하세요. 모델 파일(.mdl)은 별도의 내보내기 형식입니다.

새로고침하거나 탭을 닫으면 편집 화면이 초기화됩니다. 공용 크롬북에서는 수업이 끝나면 다운로드한 사진·학습 자료를 학교의 파일 관리 기준에 따라 정리하세요.

연결과 권한

텍스트·이미지 활동은 회원가입 없이 브라우저에서 실행됩니다. 이미지 특징을 추출할 때 같은 사이트에서 공통 모델을 읽습니다. 소리 활동은 처음 녹음할 때 외부 공통 모델을 받을 인터넷 연결과 마이크 권한이 필요합니다. 카메라와 마이크는 HTTPS 주소 또는 이 컴퓨터의 로컬 주소에서 사용하세요.
