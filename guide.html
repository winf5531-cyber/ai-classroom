목차

처음 시작하기실습별 안내 예측 점수 읽기저장하고 다시 열기 카메라와 마이크 설정

처음 시작하기

학생은 크롬북에서 로그인 없이 실습할 수 있습니다. 지도학습 수업에서는 학생이 예시에 그룹 이름을 붙여 AI를 학습시키고, 새 예시를 어느 그룹으로 분류하는지 확인합니다.

티처블 머신으로 사진, 소리, 자세를 분류해 봤다면 이번에는 문장이나 숫자로 실습해 보세요. 사진이나 자세를 촬영하려면 카메라가 필요하고, 소리를 녹음하려면 마이크가 필요합니다.

  1. 그룹별로 예시 모으기구분하고 싶은 그룹을 두 개 이상 만드세요. 그룹마다 서로 다른 예시를 세 개 이상 넣으세요.
  2. AI 모델 학습하기‘AI 학습’ 영역에서 학습 버튼을 누르고 완료될 때까지 기다리세요.
  3. 새 자료로 테스트하기‘결과 테스트’에서 학습에 쓰지 않은 자료를 넣고 예상한 그룹과 결과를 비교하세요.

실습별 안내

텍스트 분류 실습 — 긍정과 부정 문장 구분하기

‘긍정’과 ‘부정’ 그룹을 만드세요. 추가를 누르고 “친구와 함께 놀아서 즐거웠다.”처럼 한 줄에 한 문장씩 입력하세요. 문장 추가를 누르면 해당 그룹에 담깁니다.

학습한 뒤 새 문장을 입력하고 분류하기를 누르세요. “환경을 보호한다.”와 “환경을 보호하지 않는다.”처럼 겹치는 표현이 많은 문장은 어떤 결과가 나오는지 비교해 보세요.

감정 분석 수업에서 쓸 테스트 문장과 활동 질문 보기

학습실에서 ‘한국어 감정’ 예제 열기

  1. AI 학습실을 새 탭에서 열고 화면 위쪽의 파일을 누르세요. 작은 화면에서는 오른쪽 위 메뉴(☰)를 먼저 여세요.
  2. 예제 데이터에 마우스를 올리세요. 터치 화면에서는 한 번 누르세요. 나타난 목록에서 한국어 감정을 선택하세요.
  3. ‘학습 데이터’에 긍정과 부정 그룹이 생기고 문장이 다섯 개씩 들어갑니다. AI 모델 학습하기를 눌러 연습을 시작하세요.

아래 버튼을 누르면 한국어-감정.json이 다운로드됩니다. 다시 쓸 때는 학습실의 파일 메뉴에서 학습 데이터 불러오기를 누르고 이 파일을 선택하세요.

이미지 분류 실습 — 색과 도형을 구분하는 AI 만들기

그룹마다 서로 다른 사진을 세 장 이상 모으세요. 사진 파일을 올리거나 카메라로 촬영할 수 있습니다. 학습이 끝나면 새 사진 한 장으로 테스트하세요.

‘색과 도형’ 예제에는 빨간 원, 파란 네모, 초록 세모가 들어 있습니다. 예제를 학습시킨 뒤 직접 그린 도형을 올려 어떤 그룹으로 분류하는지 살펴보세요.

학습실에서 ‘색과 도형’ 예제 열기

  1. AI 학습실을 새 탭에서 열고 화면 위쪽의 파일을 누르세요. 작은 화면에서는 오른쪽 위 메뉴(☰)를 먼저 여세요.
  2. 예제 데이터에 마우스를 올리세요. 터치 화면에서는 한 번 누르세요. 나타난 목록에서 색과 도형을 선택하세요.
  3. ‘학습 데이터’에 빨간 원, 파란 네모, 초록 세모 그룹이 생기고 그림이 여덟 장씩 들어갑니다. AI 모델 학습하기를 눌러 연습을 시작하세요.

예제 파일을 내 기기에 저장하려면

아래 버튼을 누르면 색과-도형.json이 다운로드됩니다. 다시 쓸 때는 학습실의 파일 메뉴에서 학습 데이터 불러오기를 누르고 이 파일을 선택하세요.

숫자 데이터 분류 실습 — 가로와 세로 길이로 도형 구분하기

가로와 세로 길이로 ‘가로가 긴 도형’과 ‘세로가 긴 도형’을 구분해 보세요. 가로가 긴 그룹에는 8, 2, 세로가 긴 그룹에는 2, 8처럼 입력합니다.

추가를 누르고 한 줄에 한 묶음씩 입력하세요. 모든 예시에서 숫자의 개수와 순서를 맞추세요. 학습한 뒤 새 묶음 9, 3을 입력하고 분류하기를 누르세요.

소리 분류 실습 — 박수와 책상 두드리는 소리 구분하기

‘박수’와 ‘책상 두드리기’ 그룹을 만드세요. 각 그룹에서 녹음을 누르고 해당 소리를 내세요. 예시가 충분히 모이면 녹음을 중지하세요.

학습한 뒤 ‘결과 테스트’에서 녹음을 눌러 새 소리를 들려주세요. 소리를 내는 사람이나 마이크와의 거리를 바꿔 결과를 비교해 보세요.

자세 분류 실습 — 웹캠으로 손을 든 자세 구분하기

동작 인식 수업에서는 한 손을 들었을 때와 두 손을 들었을 때의 관절 위치를 비교해 보세요. 학생이 직접 자세를 취하고 새 각도에서도 모델이 구분하는지 확인할 수 있습니다.

  1. ‘한 손 들기’와 ‘두 손 들기’ 그룹을 만드세요. 한 그룹에서 카메라 열기를 누르고 한 사람의 양쪽 어깨와 팔이 보이도록 서세요.
  2. 팔 위에 점과 선이 보이면 이 자세 촬영을 누르세요. 한 번 누를 때마다 그 순간의 관절 좌표가 예시 한 개로 저장됩니다. 위치나 각도를 조금씩 바꿔 반복한 뒤 카메라 닫기를 누르세요.
  3. 학습 후 ‘결과 테스트’에서 새 자세를 취하고 분류하기를 누르세요. 사진 파일 선택으로 한 장씩 추가하거나 테스트할 수도 있습니다.

저장되는 자료 영상은 브라우저에서 처리되며, 자세 학습 파일에는 그룹 이름과 관절 좌표가 들어갑니다.

예측 점수 읽기

점수는 새 예시가 각 그룹에 얼마나 가깝다고 모델이 판단했는지 100점 기준으로 보여 줍니다. 예를 들어 ‘긍정’이 90점이어도 실제 정답률은 별도로 확인해야 합니다.

테스트 자료의 정답을 먼저 적고 예측 결과와 비교하세요. 자주 틀리는 경우를 찾아 비슷한 예시를 학습 그룹에 보충한 뒤, 다른 자료로 다시 테스트하세요.

저장하고 다시 열기

수업을 마칠 때
파일 → 학습 데이터 저장을 선택하세요. 내려받은 JSON 파일에 그룹 이름과 예시가 들어 있습니다. 새로고침하거나 예제를 바꾸기 전에 먼저 저장하세요.
다음 시간에 이어서 할 때
파일 → 학습 데이터 불러오기에서 저장한 JSON을 열고 모델을 다시 학습하세요. 학습한 모델 자체를 내보낼 때는 별도의 모델 파일(.mdl)을 사용합니다.

공용 크롬북에서는 수업이 끝나면 다운로드한 사진과 학습 파일을 학교의 파일 관리 기준에 따라 정리하세요.

카메라와 마이크 설정

카메라나 마이크를 열 수 없어요.
HTTPS 주소로 접속하고 브라우저의 사이트 권한을 확인하세요. 이 컴퓨터에서 직접 실행할 때는 로컬 주소도 사용할 수 있습니다. 이미지 분류와 자세 분류에서는 사진 파일을 올려 실습할 수도 있습니다.
자세 미리보기에 빨간 X가 보여요.
카메라가 여러 대라면 미리보기 위의 사용할 카메라에서 실제 웹캠을 고르세요. LG 그램에서는 LGE FHD Camera를 선택하세요.
첫 녹음이 시작되지 않아요.
소리 활동은 처음에 외부에서 공통 음성 모델을 받아옵니다. 인터넷 연결과 마이크 권한을 확인하세요. 이미지와 자세 활동용 모델은 AI 학습실 사이트에서 받아옵니다.
